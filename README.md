# LecLotto GitHub Pages

このフォルダの内容をGitHub Pagesの公開元へそのまま配置できます。

- index.html: トップページ
- privacy.html: App Store Connectの「プライバシーポリシーURL」に使用
- support.html: App Store Connectの「サポートURL」に使用

## 公開前に1点だけ要確認

support.html の「お問い合わせ」欄には、公開用のメールアドレスまたは問い合わせフォームURLを追加してください。

## URL例

GitHub Pagesの公開URLが

https://USERNAME.github.io/LecLotto/

の場合:

- Privacy Policy:
  https://USERNAME.github.io/LecLotto/privacy.html

- Support:
  https://USERNAME.github.io/LecLotto/support.html
